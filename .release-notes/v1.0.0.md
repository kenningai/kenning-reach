# Kenning Reach v1.0.0

The first public release of Kenning Reach: one person's envision–measure–actualize process, and the experience that gives it meaning, as an MCP server over Neo4j.

## What it is

- **A formal ontology.** `docs/design/ontology/v3.0.0.tql` declares the graph's shape in TypeQL. The code is derived from it and gated against it: `gate.py` proves the model two-sided on synthetic data, `audit_live.py` imports a live graph into the model and counts what it refuses, a unit test fails if the code's type sets drift from the model, and an integration test exercises every rule on a real Neo4j. The ontology's own version (v3.0.0) is the model's name and is independent of the package version.
- **Two layers.** Process (Genesis, Envisioning, TemporalFrame; seven edges) is written only by the six process tools. Experience (eighteen node types, twelve edge types) is written by `create_entities` / `create_relations` under the endpoint rules the model declares.
- **22 tools**, no write-Cypher tool by design.
- **A person's own deployment.** `deploy/` holds one compose file (Neo4j with APOC and GDS, plus Reach) for the person's own machine, and a Claude Code project whose `CLAUDE.md` is the operator discipline: write only in the person's words, never infer, read back before writing. With Remote Control the same session is reachable from the Claude phone app; the graph never leaves the machine.
